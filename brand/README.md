# Agricoders brand files

Master files from the Agricoders Brand and Template Guidelines v1.0. Use these files only: never redraw,
trace, recolour or crop the logo.

| File | Use |
|---|---|
| agricoders-logo-disc.png | Master logo (Logo Navy circuit tree) in its white disc, for dark backgrounds: Forest, Pine, Night Field |
| agricoders-logo-navy.png | Master logo on a transparent background, for White or Mist |
| cropmanager-glyph.png | CropManager glyph: white sprout in a Leaf Green disc, for icon circles, the sidebar and the favicon |

`python scripts/brand/make_assets.py` derives the web favicon and the mobile icon, adaptive icon and splash from these.
